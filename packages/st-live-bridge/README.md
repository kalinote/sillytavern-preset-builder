# Preset Studio Live Bridge

This repository is the generated SillyTavern extension mirror for Preset Studio Live Bridge.

Version `0.1.x` is a bootstrap release used to verify extension discovery, installation, updates, and uninstallation. It does not provide live debugging, prompt capture, or access to the active SillyTavern page context yet.

This release has no SillyTavern settings panel. After installation, find it in SillyTavern's extension management list and refresh the SillyTavern page to load or unload its code; a server restart is not required.

The authoritative source lives in [`packages/st-live-bridge`](https://github.com/kalinote/sillytavern-preset-builder/tree/main/packages/st-live-bridge). Changes are published automatically to [`kalinote/SPB-live-bridge`](https://github.com/kalinote/SPB-live-bridge); do not edit the generated mirror directly.
